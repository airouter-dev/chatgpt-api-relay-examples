# ChatGPT API relay на русском

AI ROUTER - это OpenAI-совместимый ChatGPT API relay для разработчиков. Он подходит для приложений, скриптов, внутренних инструментов и coding-agent workflow.

Русская страница: https://ai-router.dev/ru

## Что дает AI ROUTER

- OpenAI-compatible endpoint.
- API key management.
- Usage tracking.
- Daily and weekly ChatGPT API plans.
- Dashboard visibility for quota, balance, and subscription status.

## Endpoint

```text
https://api.ai-router.dev/v1
```

## Когда это полезно

- Нужно быстро протестировать ChatGPT API в приложении.
- Уже есть код на OpenAI SDK, и хочется заменить только `base_url`.
- Требуется отдельный API key для скрипта или внутреннего инструмента.
- Нужно видеть расход и остаток квоты после тестов.

AI ROUTER не является официальным сервисом OpenAI. Это независимый relay с OpenAI-совместимыми request patterns.
