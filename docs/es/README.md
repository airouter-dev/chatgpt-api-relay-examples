# AI ROUTER relay de ChatGPT API

AI ROUTER es un relay de ChatGPT API compatible con OpenAI para desarrolladores que necesitan claves API, seguimiento de uso y planes diarios o semanales.

Language: Español (es-ES)  
Website: https://ai-router.dev/es  
Direction: ltr

## Endpoint

```text
https://api.ai-router.dev/v1
```

## What AI ROUTER provides

- OpenAI-compatible endpoint: `https://api.ai-router.dev/v1`.
- API key creation and management from the dashboard.
- Usage, balance, quota, and subscription visibility.
- Daily and weekly ChatGPT API plans for testing and ongoing workflows.
- Examples for curl, Python, and Node.js.

## Quick start

1. Create an AI ROUTER account.
2. Choose a daily or weekly ChatGPT API plan, or add balance.
3. Create an API key.
4. Set your OpenAI-compatible base URL to `https://api.ai-router.dev/v1`.
5. Send a small test request and check usage in the dashboard.
