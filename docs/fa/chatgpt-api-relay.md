# رله ChatGPT API به فارسی

AI ROUTER یک ChatGPT API relay سازگار با OpenAI برای توسعه دهندگان است. این سرویس برای برنامه های AI، اسکریپت ها، ابزارهای داخلی و جریان های کاری coding agent کاربرد دارد.

صفحه فارسی: https://ai-router.dev/fa

## AI ROUTER چه کاری انجام می دهد

- ارائه endpoint سازگار با OpenAI.
- مدیریت API key.
- مشاهده مصرف و سهمیه.
- پلن های روزانه و هفتگی ChatGPT API.
- نمایش موجودی، quota و وضعیت اشتراک در داشبورد.

## Endpoint

```text
https://api.ai-router.dev/v1
```

## چه زمانی مفید است

- وقتی می خواهید ChatGPT API را سریع در یک برنامه تست کنید.
- وقتی کد OpenAI SDK دارید و فقط می خواهید `base_url` را تغییر دهید.
- وقتی برای یک اسکریپت یا ابزار داخلی API key جداگانه می خواهید.
- وقتی باید مصرف و سهمیه باقی مانده را بعد از تست بررسی کنید.

AI ROUTER سرویس رسمی OpenAI نیست. این سرویس یک relay مستقل با request pattern سازگار با OpenAI است.
