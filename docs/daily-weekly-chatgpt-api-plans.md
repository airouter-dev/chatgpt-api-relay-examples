# Daily and Weekly ChatGPT API Plans

AI ROUTER supports ChatGPT API plans designed for testing, short projects, and ongoing development workflows.

The public product catalog includes daily and weekly plan patterns. Exact model availability, quota rules, and pricing are shown in the AI ROUTER dashboard.

## Why daily plans are useful

Daily plans are useful when you want to test a workflow before committing more budget. They are a good fit for:

- New app prototypes.
- One-day integration tests.
- Prompt and response-format testing.
- Temporary coding-agent usage.
- Short automation jobs.

## Why weekly plans are useful

Weekly plans are useful when a workflow has already passed basic testing and needs a few days of repeated usage. They are a good fit for:

- Small team development.
- Demo periods.
- Internal tool testing.
- Coding-agent workflows.
- Ongoing scripts with predictable usage.

## Recommended plan selection

1. Start with a smaller daily plan.
2. Verify the endpoint, model name, and request format.
3. Check usage tracking.
4. Move to a weekly plan only when usage is predictable.

AI ROUTER does not market unlimited usage. Plans have clear quota and period rules shown in the dashboard.
