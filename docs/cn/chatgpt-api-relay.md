# ChatGPT API 中转

AI ROUTER 是面向开发者的 ChatGPT API 中转服务，提供 OpenAI 兼容接口、API Key 管理、用量查询、日套餐和周套餐。

中文入口：https://ai-router.dev/cn

## 适合谁

- 个人开发者。
- AI 应用开发者。
- 小团队技术负责人。
- 脚本自动化用户。
- Coding Agent / Codex 工作流用户。

## 为什么需要中转

很多开发者只是想快速拿到一个可用的 ChatGPT API Key，用熟悉的 OpenAI 风格接口接入项目，同时能看清用量、额度和到期状态。AI ROUTER 把这条路径压缩成：

注册 -> 购买套餐或充值 -> 创建 API Key -> 调用接口 -> 查询用量。

## 接口地址

```text
https://api.ai-router.dev/v1
```

AI ROUTER 不是 OpenAI 官方服务。我们提供独立的大模型 API 中转服务，具体模型、套餐和价格以站内展示为准。
