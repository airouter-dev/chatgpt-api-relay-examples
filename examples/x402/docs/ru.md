# Платные изображения через x402

AI ROUTER сначала отвечает HTTP 402 с машиночитаемыми условиями оплаты. Деньги
не списываются на первом запросе: SDK x402 проверяет условия, подписывает точную
EVM-авторизацию и повторяет тот же запрос. Секрет продавца или PayAI клиенту не
нужен.

## Проверенный production-контракт

Используйте Base mainnet, USDC и одну из моделей `gpt-image-2`, `gpt-image-2.5`,
`gpt-image-2.5-sunburst`, `gpt-image-2.5-flare`. Параметр `n` обязателен (1–4),
стоимость равна `4500 × n` минимальных единиц USDC, то есть `$0.0045` за изображение.

Generations принимает JSON, а edits — multipart с файлом `image`. Примеры на Go,
Python и Node.js читают `.env` или TOML; по умолчанию включён безопасный probe.

## Безопасность ключа

Используйте отдельный кошелёк с небольшим балансом. Храните
`AI_ROUTER_X402_EVM_PRIVATE_KEY` только в локальном игнорируемом `.env` или secret
manager. Сначала проверьте условия в probe, затем явно включите pay.

Смотрите [русскую страницу AI ROUTER](https://ai-router.dev/ru) и
[английскую страницу](https://ai-router.dev) для настройки аккаунта.
