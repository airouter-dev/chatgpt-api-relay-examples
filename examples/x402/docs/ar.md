# استدعاءات الصور المدفوعة عبر x402

يعيد AI ROUTER أولاً استجابة HTTP 402 تحتوي على شروط الدفع بصيغة قابلة للقراءة
آلياً. لا يتم الدفع في الطلب الأول؛ يتحقق SDK من الشروط ويوقّع تفويض EVM دقيقاً
ثم يعيد إرسال الطلب نفسه. لا يحتاج العميل إلى سر التاجر أو سر PayAI.

## العقد الإنتاجي المتحقق

استخدم شبكة Base الرئيسية وUSDC وإحدى النماذج الأربعة: `gpt-image-2` و
`gpt-image-2.5` و`gpt-image-2.5-sunburst` و`gpt-image-2.5-flare`. يجب إرسال `n`
بين 1 و4؛ المبلغ `4500 × n` من الوحدات الذرية، أي `$0.0045` للصورة.

يستخدم generations JSON، بينما يستخدم edits نموذج multipart مع ملف `image`.
الأمثلة على Go وPython وNode.js تقرأ `.env` أو TOML وتبدأ بوضع probe الآمن.

ضع مفتاح المحفظة في ملف محلي متجاهل من Git فقط، ولا تستخدم محفظة الخزينة.
